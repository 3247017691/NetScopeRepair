## 5. 进入 M1 的条件

1. R-01 的路由结构校验必须先落地，或在 M1 报告中明确标注"仅在本机 ABI 验证过"。
2. M1 的 WPF 界面只允许调用 Application 层端口，不得直接调用 `Collectors.Windows` 的具体类型，
   也不得出现任何 `Process.Start` / `netsh` / 注册表写入。
3. 首批真实只读采集必须在用户知情且仅读的前提下进行，并保留时间戳与 provenance。
4. 任何"TUN 相关"的结论在 M0 证据集上不得发布；DX-003/004 仍不得进入运行期目录。
5. 真实外部探测需要用户明确目标与预算后单独启动，默认路径继续使用 mock。

## 6. 未覆盖的需求（明确不算通过）

## 7. 结论

M0 交付了可验证的只读增量：契约、采集、探测、存储、回放、7 条解释性规则与一条端到端演示。
它现在**能解释为什么不下结论**，这是进入 M1 前最需要的性质。越权写入、secret 泄露、
覆盖外部修改、无恢复通道四类阻断缺陷在本阶段均未出现（因为还没有写入能力）。
