# ADR 0003：M0-R2 的事实准入、证据作用域与本地回放

- 状态：已接受（2026-11-04 用户授权，11-05 补修及 G0-R1 验证完成）
- 适用：M0-R2 / G0-R1，不引入 M1 界面或任何网络设置写入口
- 前置：[ADR 0002](0002-m0-storage-and-diagnostics.md)、[G0 缺陷清单](../reports/G0-M0-findings.md)

## 决策

1. **核心封套只有一套准入条件。** Domain 内嵌发布的 JSON Schema，Serialize/Deserialize 同样验证；外部文件不能替换该契约。未知版本、非法序号/单调时间、非法引用、重复 JSON 成员均不能变成可计成功的事件。后续 payload 专用 Schema 仍是独立工作，不能用它解释核心准入不一致。
2. **未知事实保持未知。** Windows x64 原生结构在入口核对布局；没有验证的架构直接 Unsupported。metric 缺失为 null+reason，TotalMetric 为 nullable long；接口标量事实记录 Family，仅查询选中 index/family，失败时不跨族替代。单项读失败传播到域的 Partial。不会为补齐字段改真实接口。
3. **采集时按白名单最小输出。** 代理/PAC 只保留可验证的 scheme/host/port，不保存 userinfo、路径、查询或 fragment；代理映射逐项处理，语法含混时安全替换。NO_PROXY 使用独立绕过列表语法，不能当 URL 损坏其语义。牺牲敏感 PAC 路径细节，优先避免 D3 进入结果。
4. **跨样本推理先证明同一作用域。** 保留端点 ID、方法、地址族、固定请求选项摘要、观察窗、boot、墙钟和单调时间、组可比性。缺失不等于相同。取消/权限/能力缺失进入观察健康统计，不进入有效网络失败数。TLS、普通文件启动顺序、保留地址本身均不能独立升级为根因或正常模式已确认。
5. **组预算约束排队和在途任务。** 单调时钟与 elapsed timer 共同约束，组预算、用户取消和探针超时有不同原因；每个请求路径保留结果或未执行原因。真实传输按请求选择代理并隔离连接池，没有失败归属证据时标 unknown。
6. **追加确认是持久化承诺。** 打开排他写句柄后核对已有事实源，不再使用可能与磁盘不一致的 ID 缓存。打开/写入/flush 失败如实失败；坏尾或歧义阻止继续追加，不静默覆盖或拼接。只接受 UTF-8，拒绝将 UTF-8 混写到带其他 BOM 的旧文件。M2 再提供受控恢复和容量优化。
7. **M0 本地证据 payload 采用 `m0-evidence-1`。** 保存完整 typed snapshot/probe/record/diagnosis；规范化 evidence_id 可与所属对象 ID 相同，但 refs、typed 对象和 evidence metadata 必须一致。每个证据定义包含 source_event_ids 与 transformation_version。事件保留真实源时间，不按序号虚构时间。当前视图一次只重建一个网络快照；多快照历史工作台仍属于 M2。
8. **规则执行错误与诊断分开。** EvaluateDetailed 返回 Diagnoses 和 RuleEvaluationFailure，错误只记录类型/规则身份，不复制异常全文。兼容 Evaluate 在有错误时抛带 Outcome 的异常，避免悄悄丢错或制造引用不存在的“诊断”。
9. **旧日志可读，但不冒称重建了缺失事实。** Replay 对老封套继续给事件统计；只有 typed evidence 才能重建规则输入。typed 身份、来源引用或时间不一致时显式报告 EvidenceProblems。CLI 可对干净 typed 事实无网重算；完整故障包导入/迁移/规则发布不在 M0 中。

## 代价与后续

- 追加前重新读取当前日志优先保证 M0 正确性，尚无大日志性能承诺；M2 在保持同等一致性语义的前提下实现轮转、配额与索引优化。
- 当前规则一次返回一个作用域的结论；没有为增加结论数量合并不同作用域。
- 没有 provenance、有效族或时间信息的旧样本会更保守，可能只有候选或缺证，这符合证据契约。
- .NET 默认代理仍不能等同浏览器实际栈；强制 IPv4/IPv6、真实握手/认证、逐跳重定向仍待用户明确目标后验证。QA-020 本轮验证的是 mock/离线分族保留与不互相掩盖。
